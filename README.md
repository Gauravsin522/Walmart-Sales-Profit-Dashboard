Walmart Sales & Profit Dashboard

An interactive Excel dashboard project built to analyze Walmart retail sales performance using Pivot Tables, Pivot Charts, KPI cards, and slicers.

Dashboard Features
Total Revenue Analysis
Profit Tracking
Monthly Sales Trend
Top Product Categories
Top Cities by Revenue
Revenue vs Profit Comparison
Interactive Filtering with Slicers
Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting
Dashboard Design Techniques
Key Insights
Identified top-performing product categories
Analyzed monthly revenue trends
Compared sales and profit metrics
Explored city-level revenue contribution
Project Goal

The goal of this project was to create a professional retail analytics dashboard that simulates real business reporting and supports data-driven decision-making.
